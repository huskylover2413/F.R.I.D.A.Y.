# F.R.I.D.A.Y. Brain Architecture

Version: 2.0 Draft

---

# Philosophy

FRIDAY exists to reduce repetition.

She remembers what helps.

She forgets what doesn't.

She learns from every conversation.

She quietly becomes a better partner over time.

---

# The Brain

The Brain is not an AI model.

The Brain is the conductor of every subsystem.

Its responsibilities are:

- Understand the user's goal.
- Recall relevant memories.
- Decide which services are needed.
- Combine the results.
- Decide what should be learned.
- Produce one coherent response.

The Brain does NOT:

- Solve every problem itself.
- Store all data itself.
- Talk directly to hardware.
- Execute every task itself.

Instead, it coordinates specialists.

---

# Core Services

Memory

Stores long-term knowledge.

Examples:

- Preferences
- Family
- Projects
- Learning style
- Vehicles
- Goals

---

Vision

Answers:

"What am I looking at?"

Provides observations to the Brain.

---

Planner

Creates execution plans.

For obvious requests this should be deterministic.

For complex requests AI may assist.

---

Reasoning

Explains.

Compares.

Summarizes.

Draws conclusions.

---

Skills

Fast deterministic abilities.

Examples:

- Time
- Date
- Math
- Greeting

---

AI

Used when reasoning or language generation is required.

Never used when deterministic logic is better.

---

# Memory Philosophy

Permanent

- Name
- Family
- Preferences
- Coding style
- Projects
- Goals
- Vehicles
- Camera equipment

Long-Term

- Current semester
- Current classes
- Homework
- Vacation plans

Temporary

- Current meal
- Current mood
- Weather comments
- Casual conversation

Expired memories should be archived instead of deleted whenever practical.

# Design Principles

Prefer deterministic logic whenever the answer is obvious.

Use AI when judgment is required.

Every conversation should improve FRIDAY.

Every subsystem should have one responsibility.

The Brain should coordinate—not perform every task.

---

# Long-Term Vision

FRIDAY should eventually understand:

- The user
- Current projects
- The codebase
- Calendar
- Canvas
- Apple ecosystem
- FordPass
- Browser
- Camera
- Voice

without requiring repeated explanations.

The goal is an assistant that grows alongside its user over years.
